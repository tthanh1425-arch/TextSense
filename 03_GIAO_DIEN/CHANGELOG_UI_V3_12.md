# TextSense V3.12 – Chỉnh lại bố cục giao diện

- Gộp điều hướng thành một thanh header duy nhất ở đầu trang; bỏ header lặp ở khu vực phân tích.
- Header cố định khi cuộn để điều hướng luôn nhất quán.
- Thu gọn hero, cân lại tỷ lệ tiêu đề – mô tả – nút thao tác – mascot.
- Tách rõ khu vực giới thiệu và khu vực phân tích bằng khoảng cách, đường phân cách và cấp tiêu đề.
- Cân lại bố cục nhập bình luận và mascot trên desktop; ẩn mascot phụ trên mobile để tránh lặp hình.
- Giữ nguyên ID, form, tab, luồng CSV, API và logic dự đoán; chỉ chỉnh HTML cấu trúc header và CSS trình bày.
